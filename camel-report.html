抖音/快手达人种草内容效果报表.

统一达人 / 视频 / 商品 ID 建内容研究底表，补分类维度，支撑不同类型内容的互动效果横向对比。

底表建库去重与口径校验SQL 关联

四段式说明

业务问题

骆驼在抖音/快手投放大量达人短视频种草，数据散落在多个来源、口径不一，缺少统一底表，无法按达人类型、内容形式、商品类别横向比较种草效果。

个人负责

整理视频明细底表，统一视频ID/达人ID/商品ID 建立内容研究底表；补充品类、内容场景、商品卖点与内容形式分类字段；核验重复视频、缺失值与数据类型，分别统计点赞/收藏/评论/分享，统一采集时间与发布时间口径。

关键发现

覆盖 180 条视频、149 位达人；场景穿搭类内容的互动率高于纯产品展示；互动量与发布时段相关性弱、与内容形式相关性更强。

建议

优先复用高互动内容形式做小批量测试再放量；对低互动但成本高的内容形式做投放复核。商单费用、达人报价等非公开金额字段按原来源口径保留并标注为模拟演示数据，不做换算与二次推算。

取数 SQL（关联 + 去重）

-- 输入：seed_video_raw(video_id,author_id,likes,collects,comments,shares)、dim_content(video_id,content_form) -- 输出：按内容形式汇总的视频数与各互动求和；用途：报表内容形式聚合层（模拟演示数据） SELECT c.content_form, COUNT(DISTINCT v.video_id) AS video_cnt, SUM(v.likes) AS likes, SUM(v.collects) AS collects, SUM(v.comments) AS comments, SUM(v.shares) AS shares FROM ( SELECT video_id, MAX(likes) likes, MAX(collects) collects, MAX(comments) comments, MAX(shares) shares FROM seed_video_raw GROUP BY video_id -- 视频去重，避免重复采集 ) v JOIN dim_content c ON v.video_id = c.video_id GROUP BY c.content_form ORDER BY video_cnt DESC;
说明：上图内容为按内容形式聚合的互动分布示意（模拟演示数据），展示"去重 → 关联维表 → 分组汇总"的取数结果形态。

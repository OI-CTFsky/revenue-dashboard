目标达成

TARGET vs ACTUAL
口径：进度差值 = 实际成交额 − 目标；达成率 = 实际成交额 / 目标。全司当月目标 1.21 亿元，实际完成 0.97 亿元，达成率 80.3%，缺口主要来自东部与南部战区。

用户规模

USER FUNNEL BY DAY
口径：注册 → 实名认证 → 戳额 → 给额 → 成交 五级漏斗，按日堆叠。当月注册 262.7 万人，最终成交 80.7 万人，整体转化率 30.7%，其中戳额/注册率 97.6%，给额/戳额率 63.7%，成交/给额率 49.4%。

利润占比

PROFIT STRUCTURE
口径（与原 Tableau 计算字段一致）：资金成本 = 成交额×3%；获客成本 = 注册人数×0.5 元/人；毛利 = 应收利息 − 资金成本 − 获客成本 − 逾期金额；各占比 = 对应项 / 应收利息。当月逾期侵蚀 31.3% 的利息收入，导致整体毛利转负，风险处置是利润修复的首要杠杆。
